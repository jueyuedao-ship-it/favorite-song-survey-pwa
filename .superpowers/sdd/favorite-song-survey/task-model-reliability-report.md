# Actual-model reliability integration report

Implemented the bounded core Worker pipeline, using only public captured source/model fixtures. No private Setup keys, live provider calls, deployment, collector, or UI changes were made by this task.

- Conditional strict decoding represents one supplied canonical recording only after native YouTube metadata, title, and artist-hint guards pass. Credits/tags remain optional; unknown kind stays `other` and requires metadata review. A certain recording can attach the answer independently of that review.
- Identity/JSON/unsafe-URL failures remain hard failures. Independently supported credits, aliases, and tags survive rejected secondary claims. Bounded warnings and the exact raw model response remain in privileged job/results and the change feed; public song detail excludes those predictions. Malformed raw output is retained for privileged review without publishing a recording.
- A complete uploader name equal to the native author field is grounded to that exact field while preserving the original model quote in raw review. Role-shaped/substring channel headers, title labels, compound names, social handles, and unrelated sources retain negative guards. Factual human/synthetic voice claims are distinguished from voice quality, genre, mood, and lyric inference.
- Missing descriptions trigger one bounded Japanese lookup grounded in the native title/author, then extraction of at most two new pages. The exact supplied recording is extracted first. Markdown links and actually retrieved watch/short/embed equivalents survive excerpt bounds; a requested URL is never injected into unrelated source evidence. Quota/provider failure preserves answers and established facts with an honest review warning.
- Active canonical entities reuse existing aliases and NFKC/case variations. Locked credit roles are checked before entity creation. Ambiguity and the bounded 60-row entity/alias lookup conservatively skip the claim for review rather than creating a duplicate.
- All 50 initial criteria now describe meaningful tag semantics. Migration `0004_tag_criteria.sql` upgrades only untouched revision-1 exact legacy defaults and preserves admin-edited criteria, with normal feed triggers. The complete inference transport budget remains <=7600 estimated tokens including schema, all 50 definitions and output allowance. Existing atomic Free credit cap, lease, request-size and retry guards remain in use.

Evidence: TDD reproduced discarded actual-model facts, duplicate corrected identity, voice-quality inference, absent descriptor investigation, failed descriptor fallback, lost actual links, lyric-based mood/genre, malformed raw loss and nested uploader substring attribution before their respective fixes. Real D1 fixtures independently retain uploader/composer for all four actual captures, vocalist for three (Overdose stays unconfirmed), reject unlinked J-POP/lyric predictions, and preserve the supported Wind human-voice tag with English reasoning. New stages are measured against the <=50 D1 statement bound. Some old all-or-nothing assertions intentionally changed to assert valid identity attachment and continued rejection of unsupported claims.

A long scoped run and the first final full run reproduced Windows Miniflare `connect EADDRINUSE 127.0.0.1` after about 84-90 fixtures (first final run: 143 passed, 33 failures cascading across 27 research and 6 API cases). Recreating runtimes alone did not fix global port exhaustion. Inspection of the bundled `DispatchFetchDispatcher.dispatch` confirmed unconditional `options.reset = true`, and 5934 loopback TIME_WAIT sockets were observed. Root authorized a strictly test-only workaround: on Windows with `NODE_ENV=test`, only explicitly registered `mf.ready` loopback origins route reset calls through an eight-connection Pool with reset disabled. Headers, bodies, real workerd/D1 and concurrency remain intact; runtime disposal closes pooled connections and cleanup restores the original dispatch prototype. Linux and unregistered/public origins are untouched. Scoped concurrent-delete and duplicate-concurrency checks both passed. The justified full rerun then passed all 176 tests; loopback TIME_WAIT was down to 37 during that run. No dependency files, system TCP settings or production network behavior were changed.

Final validation: `npm.cmd test` passed 8 files / 176 tests (122.59s); `npm.cmd run typecheck` passed; `npm.cmd run build` passed (119.82 KiB Worker dry run and web build). `git diff --check` passed. The only changes after the passing type/build checks were test transport integration/formatting and optional type declarations, with transport typecheck separately passing. Live spaced provider replay, deployed Free CPU profiling, staging/public acceptance and human browser checks remain Root-owned gates.
